**New since 0.1.3**
- **macOS app (experimental):** a universal app (Apple silicon and Intel) built by GitHub Actions, in the same release as the Windows zip. It has **never been run on a Mac by its author**: please report what you see. It is not signed by an Apple developer and not notarized (ad-hoc signature only), so macOS asks you to allow it; `READ-ME-FIRST.txt` in the zip says how. A program opened from Finder does not get your shell's `PATH`, so the app now also looks for `claude` where it is usually put (`~/.local/bin`, `~/.claude/local`, `~/.npm-global/bin`, `~/.bun/bin`, `~/.volta/bin`, `/opt/homebrew/bin`, `/usr/local/bin`). Not on macOS: notifications and the tray icon; the terminal page has never been tried there.
- Release builds: the macOS build is a workflow of its own, so a problem there never stops the Windows release.

Everything else is as in 0.1.3 (see its notes: the board, project defaults, archive, project trust). Details: [docs/NOTES.md](https://github.com/nathak/karsenia/blob/main/docs/NOTES.md).
