**License change: from 0.1.5 the program is GPL-3.0-only.** The desktop app is built with Slint, which is now used under its GNU GPLv3 option, so the program as a whole is GPL-3.0-only (before: the source code was MIT and the program was built with Slint under its Royalty-free Desktop License). Releases up to 0.1.4 stay as they were published. The zips now hold `LICENSE` (GPL-3.0) and `THIRD-PARTY-NOTICES.txt` (620 crates, their licenses and texts, the web page's scripts and the fonts); the source of a release is this repository at its tag.

**New since 0.1.4**
- `SECURITY.md` (how to report a vulnerability) and `CONTRIBUTING.md` (contributions are accepted under GPL-3.0-only and reviewed by the maintainer).
- The Windows program carries its product name, description, version and copyright line (Explorer → Properties → Details).
- The read-me files in the zips say where the source is and how to remove the app.

Nothing else changes in how the program works. The program is still not signed by a publisher; see `docs/signing.md`. Details: [docs/NOTES.md](https://github.com/nathak/karsenia/blob/main/docs/NOTES.md).
