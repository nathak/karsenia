Version 0.1.2 was never released (its first build failed on the new build pipeline); 0.1.3 is the next release after 0.1.1.

**New since 0.1.1**
- **Board** (sidebar, `Alt+8`): one line for every chat of every account: state, waiting questions, progress, changes and merge state of worktree chats, cost, and signs worth a look (the same call repeated, many files edited, calls a guard held, long work, a failed turn, a full context window). It only shows; a click goes to the chat. Worktrees are looked at through the same checks as "병합 점검", a few at a time and only while the page is open. See `docs/design/board.md`.
- **Account choice** is one select box in the sidebar (no more tab per account); gateways are not shown apart; the chat header keeps the status and moves what does not fit into a **more** menu.
- **Project defaults**: the new-chat form remembers the model, permission mode, account and worktree choice per project and fills them in (never bypass-permissions, never for provider or container chats). A start right after the form filled itself in is held back until you have seen it. **Recent projects** are listed under the folder field.
- **Archive** a chat instead of deleting it (hidden unless shown, working or waiting; not while a turn or background work runs; a new message brings it back).
- **Project trust**: the project check card can remember "trust" for the project (per account, only the exact settings shown, never a declined question; worktree chats still ask per chat); the form shows it and can forget it.
- Notes and skills of a worktree chat are filed under its project. Chat text can be selected by dragging and copied also from bold, code and link text.
- The Windows zip is now built by GitHub Actions from the tag (tests first); CI runs the Linux test suite and a Windows compile check on every push.

Known limits: the board's settings check and the `git status` after it are two moments (a command run in a working chat could write a content filter between them; the board looks at working chats at most every 30 s and shows "settings changed", but that is a reduction, not a fix); nothing of the board was tried on Windows. Details: [docs/NOTES.md](https://github.com/nathak/karsenia/blob/main/docs/NOTES.md).
